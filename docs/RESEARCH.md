# 영어 학습 서비스 조사 — EngMon이 참고한 것과 참고하지 않은 것

> 조사 시점: 2026-09 (1차 조사 → 2차 보강) · 대상: 영어 학습 웹사이트·매거진·앱 27곳
> 목적: 1~4호 본문 보강과 5~52호 계획을 세우기 전에, "무엇이 이미 흔하고 무엇이 드문지"를 확인합니다.

이 문서는 **기획 근거**입니다. 실제 구현 규칙은 `README.md`, 콘텐츠 데이터는 `issues.js`에 있습니다.
`docs/`는 공개 사이트에 배포되지 않습니다(`tools/stage-site.mjs`의 공개 목록에 없음).

---

## 0. 이 문서가 답하는 세 가지 질문

1. **무엇이 이미 흔한가** — 그래서 흔한 것만으로는 값을 매기기 어려운가.
2. **무엇이 드문가** — 그리고 그 드문 것을 "정적 사이트 + 외부 요청 0" 제약 안에서 만들 수 있는가.
3. **무엇을 일부러 안 가져왔는가** — 만들 수 없는 것을 억지로 흉내 내지 않았는가.

요약하면 EngMon이 노리는 자리는 **"띄엄띄엄 나오는 좋은 레슨"이 아니라 "1년을 끊기지 않고 이어 붙인 커리큘럼"** 입니다.
뉴스 레슨은 넘칩니다. 52주 로드맵과 진행률은 드뭅니다.

## 1. 한눈에 보는 비교표

"정적 사이트 + 외부 요청 0"이라는 EngMon의 제약 안에서 가져올 수 있는 것만 표시했습니다.
`⚠️ 부분`은 형태만 빌리고 완전히 같지는 않다는 뜻, `✖ 안 가져옴`은 7장에 이유가 있습니다.

| 서비스 | 유형 | 그쪽의 핵심 | EngMon에 담은 방식 |
| --- | --- | --- | --- |
| **News in Levels** | 뉴스 | 같은 기사를 3단계 난이도로 | 한 주 안에서 섹션마다 레벨 표시(A2~C1) |
| **Breaking News English** | 뉴스 | 주 2회 새 레슨, 레벨별 지문 + 어휘·문제 세트 | 주 1회 새 호, 16~18개 섹션 세트 |
| **VOA Learning English** | 뉴스 | 느린 속도 + 어휘 설명이 붙은 뉴스 | 문장 단위 재생 + 3단계 속도(0.75×/1×/1.25×) |
| **BBC Learning English** | 종합 | 문법·발음·어휘를 코스로 묶음 | 섹션 kind로 코스 구성(문법·발음·어휘…) |
| **BBC 6 Minute English** | 대화 | 6분 대화 하나에 어휘 6개 | 회화 섹션 + 그 회화 전용 어휘(`items`) |

| **Duolingo** | 문제풀이 | 즉시 채점 + 연속 학습일 | 확인 문제 즉시 채점 + `monsterlab.days` 연속일 |

| **Hot English / Spotlight** | 매거진 | 정기 구독, 주제별 잡지 구성 | 주제별 52주 목차 + 계획 카드 |

| **Grammarly / AI 튜터** | 교정 | 문장을 실시간으로 고쳐 줌 | ✖ 안 가져옴 — 외부 API 의존 |

## 2. 유형별로 본 것

### 2.1 뉴스 기반 학습 (가장 crowded한 영역)

- **공통 골격**: 지문 1편 → 어휘 목록 → 이해 문제 → 토론 질문.
- **차별점이 되는 것**: ① 난이도 단계, ② 오디오, ③ 주제의 신선도.
- **한계**: 대부분 **하루/한 주 단위로 끊긴 콘텐츠**입니다. 1년을 이어 붙이는 커리큘럼이 없습니다.
- → EngMon의 자리: **연속성**입니다. 52주 로드맵과 진행률이 이 영역에서 드문 무기입니다.

### 2.2 매거진형 (British Council Magazine zone, Hot English 등)

- B1·B2 학습자용 기사 + 상호작용 활동. **문화·기념일 주제**가 많습니다("세계 교사의 날", "세계 오존의 날").
- 장점: 문화 지식이 자연스럽게 붙습니다. 단점: 문법·발음처럼 **기능 훈련은 없습니다**.
- → EngMon은 기사를 **주제(theme)** 로 삼고, 기능 훈련(문법·발음·구동사)을 그 위에 얹는 방식을 택했습니다.
  즉 주제는 매거진처럼, 훈련은 코스처럼 가져갑니다.

### 2.3 리더·플래시카드 (LingQ, Readlang, Anki)

- **LingQ / Readlang**: 읽다가 모르는 단어를 클릭해 저장 → 그 자리에서 뜻 확인.
- **Anki**: 간격 반복(0 → 1 → 3 → 7 → 16 → 35일)으로 장기 기억.
- → EngMon: 두 기능을 **한 화면에** 넣었습니다(`items`의 저장 버튼 + 복습 카드).
  서버가 없으므로 간격 계산과 저장을 모두 `localStorage`에서 합니다.
  Readlang의 "문장 전체를 저장"은 `items`의 `example`로 흡수했습니다.

### 2.4 회화·발음 앱 (Cake, 스픽, ELSA, YouGlish)

- 축약 발음(`going to → gonna`)과 **따라 말하기**가 핵심 가치입니다.
- 진짜 강점인 **발음 채점**은 브라우저 음성합성만으로는 만들 수 없습니다.
  YouGlish처럼 실제 원어민 영상을 끌어오는 방식은 외부 요청이 생깁니다.
- → 대신 "왜 그렇게 들리는지"를 설명하는 **발음 포인트 섹션**으로 바꿨습니다.
  (점수를 줄 수 없으면, 알아듣는 능력을 키우는 쪽을 택함)

### 2.5 문제풀이·시험 (Duolingo, 토익 앱)

- 즉시 채점 + 점수 + 다시 풀기. 학습 리듬(연속일)을 게임처럼 보여 줍니다.
- → EngMon: 채점·점수·다시 풀기 + 오늘 활동 수·연속 학습일까지 담았습니다.

### 2.6 영상·1:1 수업 (Lingopie, Cambly, italki, Lingoda)

- 가장 강력한 학습 형태지만 **사람·서버·저작권**이 필요합니다.
- → 담지 않았습니다(7장). 대신 자기주도 학습의 닫힌 고리로 승부합니다.

## 3. 기능 단위 격차 분석 (조사 → 결정)

| 기능 | 잘하는 서비스 | EngMon | 결정 |
| --- | --- | --- | --- |
| 난이도 단계 | News in Levels | 섹션별 레벨 표시 ✅ | 유지 |
| 오디오 | VOA, Cake | 브라우저 음성합성 ✅ | 유지(비용 0) |
| 단어 저장 | LingQ | 항목별 저장 ✅ | 유지 |
| 간격 반복 | Anki | 6단계 카드 ✅ | 유지 |
| 받아쓰기 채점 | 받아쓰기 앱 | 오답 단어 표시 ✅ | 유지 |
| 문화·시사 맥락 | British Council | `culture` 섹션 ✅ | 1차 보강에서 4주 모두 채움 |
| 주의 학습목표 | 대부분 ❌ | `goals` 섹션 ✅ | 1차 보강(W01~04) |
| 다음 주 미리보기 | Blinkist류 | 계획 카드 ✅ | 1차 보강, 2차에서 정확화 |
| 발음 채점 | ELSA | 불가 ❌ | 대체(설명+듣기) |
| 1년 커리큘럼 | 거의 없음 ✅ | 52주 로드맵 ✅ | 강화 |

### 3.1 1차 보강에서 찾은 구멍 (W01~W04)

- **W02(직장 영어)** 만 **발음 섹션이 없고 독해 지문도 없었습니다.** (12개 섹션, 다른 호는 15개 이상)
- **W01(여행 영어)** 에는 **독해 섹션이 없었습니다.** 회화·문화는 있었지만 "긴 글을 읽고 요약하는" 훈련이 빠져 있었습니다.
- 모든 호에 "이 주를 마치면 무엇을 할 수 있는가"를 알려 주는 **학습목표가 없었습니다.**
- 학습자는 표지의 통계(섹션·분·단어 수)만 보고 무엇을 얻을지 알 수 없었습니다.

### 3.2 2차 보강에서 찾은 구멍 (W05~W52)

- `theme`·`title`·`summary` **세 필드뿐**이었습니다. 학습자가 "이 주를 들을까"를 판단할 근거가 없었습니다.
- 로드맵에서 준비 중인 주를 눌러도 **"준비 중입니다" 한 줄**뿐이었습니다.
- 계획의 **구성 요약(`parts`)이 실제 발행 골격보다 적게** 적혀 있었습니다.
  (학습목표·문화·유머·해설 노트를 빠뜨리고 "약 15개 섹션"으로 끝났음 — 실제 발행분은 16~18개)

### 3.3 아직 남은 것 (의도적으로 남긴 격차)

- **발음 채점**: 브라우저만으로는 불가. 남겨 둡니다.
- **원어민 음성**: 음성합성의 음질 한계. 유료 음성 파일을 넣기 전까지는 이대로 갑니다.
- **개인화 추천**: 서버·계정이 필요합니다. 지금은 저장 데이터로 대신합니다.

## 4. EngMon에 반영한 원칙

1. **읽기 → 듣기 → 점검 → 복습이 한 화면에서 닫힌다.** (여러 사이트를 오가게 하지 않음)
2. **영어가 본문, 한국어는 도움말.** 번역은 가릴 수 있어야 한다(영어로 생각하는 연습).
3. **난이도는 섹션 단위로 표시한다.** 한 주 안에서 오르내려도 된다.
4. **오디오는 파일이 아니라 브라우저가 낸다.** 비용 0, 외부 요청 0.
5. **모르는 표현은 그 자리에서 저장한다.** 나중에 찾아 헤매게 하지 않는다.
6. **복습은 간격으로.** 오늘 담은 단어가 1일·3일·7일 뒤에 돌아온다.
7. **1년을 이어 붙인다.** 매 호가 독립적이지 않고 앞 호 위에 쌓인다.
8. **계획을 미리 보여 준다.** 준비 중인 주도 무엇을 배울지 알 수 있어야 신뢰가 생긴다.
9. **모든 호가 같은 순서를 따른다.** 순서가 같아야 학습 루틴이 생기고, 매주 화면을 새로 배울 필요가 없다.
10. **한 주는 한 가지 상황(situation)을 끝까지 다룬다.** 주제를 넓게 흩뿌리지 않는다.

## 5. 52주 커리큘럼 설계

### 5.1 레벨 곡선

| 분기 | 주 | 레벨 | 주제 묶음 |
| --- | --- | --- | --- |
| 1분기 | 1~13 | A2~B2 | 생활 밀착 영어 — 여행·일상·직장 |
| 2분기 | 14~26 | B1~B2 | 일과 성장 — 이메일·회의·협업 |
| 3분기 | 27~39 | B2~C1 | 세상과 문화 — 읽기·듣기·토론 |
| 4분기 | 40~52 | B2~C1 | 실전과 마무리 — 발표·시험·복습 |

- **끊김 없이 오르는 곡선**을 목표로 합니다. 같은 주제라도 분기가 올라가면 요구하는 문장 길이와
  어휘의 추상도가 올라갑니다(`plan.grammar`·`plan.words`로 미리 보임).
- 각 분기 끝(13·26·39주)에 **점검 주**를 두고, 50~52주는 1년 복습·최종 점검·다음 해 계획으로 닫습니다.

### 5.2 한 주의 표준 골격

발행된 W01~W04는 **같은 순서**를 씁니다(16~18개 섹션). 새 주를 쓸 때도 이 순서를 지킵니다.

| # | kind | 역할 | 분량 기준 |
| --- | --- | --- | --- |
| 0 | `goals` | 이 주의 학습목표 (3~4개) | 읽기 전후 자기 점검 |
| 1 | `vocabulary` | 테마 어휘 | 8~10개 |
| 2 | `phrasal` | 구동사 | 6~8개 |
| 3 | `collocation` | 연어 | 6개 |
| 4 | `grammar` | 핵심 문법 1가지 + 표 | 4개 항목 + 표 |
| 5 | `pronunciation` | 발음 포인트 | 5개 |
| 6 | `idioms` / `slang` / `natural` | 이디엄·관용·자연스러운 표현 | 3~6개 |
| 7 | `conversation` | 회화 1~2장 | 6줄 내외 |
| 8 | `listening` | 듣기·받아쓰기 | 4~5문장 |
| 9 | `reading` | 독해 지문 + 이해 질문 | 4문단 이내 |
| 10 | `writing` | 쓰기 과제(요약·메일) | 3줄 틀 |
| 11 | `discussion` | 토론 질문 | 5~6문항 |
| 12 | `culture` | 문화·시사 맥락 | 2문단 |
| 13 | `quiz` | 확인 문제 | 6문항 |
| 14 | `humor` / `note` | 유머, 한국어 해설 노트 | 선택 |

- `kind`마다 아이콘·색·문구(`mag.kind.<kind>`)가 짝을 이룹니다. 새 kind를 쓰려면 `script.js`의 `I18N`에 추가합니다.
- 예상 학습 시간은 저장하지 않습니다 — 읽기(120단어/분) + 항목·받아쓰기·문제 풀이 시간을 화면이 **계산**합니다.
  (요약에 적은 숫자와 화면 숫자가 어긋나지 않게)

### 5.3 점검 주 (13·26·39·50·51·52)

- 새 어휘를 얹지 않고 **누적 복습·오답 점검·종합 퀴즈**로 구성합니다(`plan.parts`가 다름).
- `plan.output`이 "가장 약한 섹션을 골라 다시 풀기"처럼 **자기 진단**을 요구합니다.

### 5.4 계획 카드 (발행 전인 주)

- 준비 중인 주는 `plan`(학습목표·핵심 문법·핵심 어휘·발음 포인트·산출 과제·구성 예정 섹션)을 보여 줍니다.
