## 1. 전제와 제약

이 플랜은 EngMon의 지금 구조를 바꾸지 않습니다. 제약이 곧 전략입니다.

| 지금 구조 | 수익화에 주는 의미 |
| --- | --- |
| 서버 없음 · 런타임 의존성 0 · GitHub Pages | **고정비 0.** 첫 판매부터 마진이 남습니다. 손익분기점이 없습니다 |
| 계정·로그인 없음 | 결제도 **비로그인 단건 결제**여야 합니다. 구독·정기결제는 지금 구조와 맞지 않습니다 |
| 학습 기록은 `localStorage` | 진도 기반 유료 기능(맞춤 추천 등)은 만들 수 없습니다. **콘텐츠 자체를 팝니다** |
| 본문이 이미 전부 무료 공개 | 유료 상품은 **"정보"가 아니라 "형태"** 로 값을 해야 합니다 (5장) |
| 방문 분석은 자체 수집(쿠키 없음) | 광고 재판매는 불가능하고 하지 않을 일입니다. **상품 판매가 유일한 수익원** |

> **원칙**: 무료 웹은 미끼가 아니라 자산입니다. 검색 유입이 쌓이고, 읽어 본 사람만 워크북을 삽니다.

## 3. 무엇을 유료로 두는가

웹은 전부 무료로 열어 둡니다. 유료는 **같은 내용의 다른 형태**와 **모아 둔 것**입니다.

| | 무료(웹) | 유료(워크북) |
| --- | --- | --- |
| 본문·섹션 | 전부 공개 | 동일 내용을 인쇄용으로 재조판 |
| 확인 문제 | 채점은 화면에서 | **종이에서 바로 풀고 채점** |
| 정답·해설 | 문항마다 펼쳐서 | **한 장에 모은 정답·해설집** |
| 모범 답안 | 섹션 안에 흩어져 | 쓰기·토론 모범 답안 모음 |
| 어휘 | 주마다 흩어져 | **1년 누적 어휘 색인**(뜻·예문·주차 표기) |
| 필기 | 화면 | 여백 있는 필기 레이아웃 |
| 오디오 | 브라우저 음성합성(기기마다 음질·음성 목록이 다름) | **듣기 팩 MP3** — 음성이 파일로 고정되어 기기와 무관, 미국식·영국식 악센트, 오프라인 재생 |
| 소지 | 인터넷 연결 필요 | 오프라인(PDF·인쇄·MP3) |
| 업데이트 | 즉시 반영 | 재발행분 무료 재다운로드 |

**팔지 않는 것**: 발음 채점, 1:1 교정, **사람이 낭독한 원어민 녹음**.
못 하는 것을 흉내 내면 신뢰를 잃습니다(`RESEARCH.md` 7장과 같은 판단).

> **듣기 팩은 합성 음성입니다.** 사람을 고용해 녹음하지 않았고, 그럴 비용도 52주 갱신을 감당할 시간도 없습니다.
> 대신 **합성 음성이라고 숨기지 않고 표기**합니다(약관 제3조 · 상품 설명). 악센트 구분은 미국식/영국식 발음의
> 구분이고, 국적을 말하는 표현(“미국인 낭독”)은 쓰지 않습니다.
> 실존 인물 목소리 복제는 하지 않고, 상업적 사용이 약관상 허용된 기본 음성만 씁니다(9장의 확인 목록).

## 4. 상품과 가격

| 상품 | 내용 | 가격 | 주당 환산 |
| --- | --- | --- | --- |
| 주 단권 | 발행된 주 1개(워크북 1편) | ₩4,900 | ₩4,900 |
| **분기 묶음** | 13주 + 분기 정답·해설집 + 분기 어휘 색인 + **듣기 팩(MP3)** | **₩39,000** | ₩3,000 |
| 1년 패스 | 52주 전체 + 누적 색인 + 새 주 자동 제공 | ₩129,000 | ₩2,480 |

- **주력은 분기 묶음**입니다. 단권은 "맛보기"이고, 1년 패스는 헤비 유저용입니다.
- 지금은 4주만 발행되어 있으므로 **1분기 묶음을 예약 판매**합니다:
  "1분기 13주 완성 시 순차 제공, 지금 신청하면 4주 먼저".
  이렇게 하면 재고가 4주뿐이어도 13주 가격을 받을 수 있습니다.
- 환불은 **7일 내 무조건**으로 둡니다. 디지털 상품에서 환불을 막으려 들면 문의만 늘고 평판이 깎입니다.
- 듣기 팩(MP3)은 **묶음에 포함**시키지 별도 상품으로 팔지 않습니다(「상품 하나」 원칙 — 8장).
  반응이 확인되면 그때 분리 판매를 검토하고, 그 전까지는 “지금 사면 듣기 팩 포함”이 구매 이유가 됩니다.
- 할인 상한·실수령 최저선·업그레이드 차액·인상 조건은 [`PRICING.md`](PRICING.md)에 따로 정리했습니다
  (론칭 얼리버드 30% · 코드 중첩 금지 · 이미 낸 금액 전액 공제 · 인상은 네 조건을 모두 채운 뒤).

**통화**: Gumroad는 결제를 **USD로만 처리**하고, 손님에게 보이는 화면은 자기 나라 통화로 환산해 보여 줍니다
(설정에서 표시 통화를 고를 수 있음). 그래서 해외 채널은 **USD로 값을 정합니다.**
₩39,000은 대략 **$29**입니다. 국내 채널(크몽)은 원화로 따로 정해 두면 됩니다.
환율이 흔들리면 환산 금액이 조금 달라지므로, 상품 설명에는 원화 기준가를 함께 적어 둡니다.

### 가격 근거

- 종이 영어 학습서 1권이 15,000~20,000원대이고, 주 단위로 쪼개면 회당 2,000~3,000원 수준입니다.
  분기 묶음 ₩39,000은 **주당 3,000원**이라 시중 교재와 같은 구간에 놓입니다.
- 구독형 앱은 월 10,000~20,000원대라, **3개월만 써도 분기 묶음보다 비쌉니다.** 이 비교가 영업 포인트입니다.
- 가격은 **원화로만** 정합니다. 환율에 따라 값이 흔들리면 결제 직전에 이탈합니다.

### 추천: Gumroad (주) + 크몽 (부)

1. **Gumroad** — 상품 파일을 올리면 결제 후 자동으로 다운로드 링크가 나가고, 카드·세금(VAT) 처리를 대행합니다.
   사이트에는 링크 **한 줄**만 붙습니다(서버·계정·결제 데이터가 우리 쪽에 남지 않음).
2. **크몽** — 국내 구매자는 해외 결제 페이지에서 한 번 멈칫합니다. 국내 결제·간편결제가 되는 채널을 하나 병행합니다.
   수수료가 높은 대신 **사업자등록 없이 시작**할 수 있어 검증 단계에 맞습니다.
3. **슬러그(Stripe)는 쓰지 않습니다.** 한국 사업자 명의로 판매자 계정을 만들 수 없어, 확인에 시간을 쓰면 손해입니다.

**Gumroad 수수료 구조 (확인 시점 2026-09)**

| 항목 | 값 |
| --- | --- |
| 월 이용료 | $0 (요금제 없음) |
| **사이트 링크로 들어온 판매** | 판매액의 **10% + $0.50** |
| Discover(마켓플레이스)에서 팔린 건 | **30%** 정액 |
| 세금·부가세 | Gumroad가 Merchant of Record로 대행 (추가 비용 없음) |

- 우리는 **사이트에서 링크로만 유도**하므로 대부분 10% + $0.50 구간입니다.
- $29 한 건을 팔면 $2.90 + $0.50 = $3.40이 차감되어 **실수령 $25.60**(약 ₩36,000)입니다.
- **결제는 USD로만 처리됩니다.** 표시 통화는 설정에서 고를 수 있지만 정산은 달러입니다.
- 정산은 **은행 송금 또는 PayPal**이며 나라마다 수단이 다릅니다. 한국이 정산 대상국인지는
  가입 후 정산 설정 화면에서 확인하세요(국가별 최소 정산 금액이 있습니다).

> **바뀌는 정보입니다.** 수수료율·정산 국가·세금 정책은 서비스가 자주 바꿉니다.
> 가입 직전에 각 서비스의 공식 "지원 국가 / 수수료" 페이지에서 **한 번 더 확인**하세요.

### Gumroad에 상품 하나 올리는 순서

**막히는 지점은 딱 둘입니다.** ⑴ 팔 파일이 없으면 등록할 것이 없고, ⑵ **정산 수단을 연결하지 않으면
게시(Publish)가 막힙니다**(you must connect at least one payment method before you can publish this product).
그래서 순서는 **파일 → 정산 수단 → 상품**입니다.

```text
0. 파는 파일을 먼저 만든다 (아래 "워크북 만들기" 참고)
1. 로그인 → 좌측 상단 Products → New product
2. 상품 유형에서 Digital product 선택 (다운로드 파일을 파는 형태)
3. Name  : EngMon 1분기 워크북 (여행·직장·일상·뉴스 영어)
4. Content 탭 → PDF 업로드 (파일당 250MB까지)
5. Customize / Checkout 탭
     · 가격  : 29  (USD)
     · 설명  : 상품 소개문 붙여넣기
     · 커버  : 저장소의 og.png(1200×630)를 그대로 써도 됩니다
     · URL   : engmon-q1 처럼 짧은 슬러그
     · 환불  : 7일 내 환불 문구
6. Settings → Payments 에서 정산 수단 연결  ← 게시 전 필수
7. Publish → 링크 복사 (gumroad.com/l/슬러그)
```

- 화면 이름은 조금씩 바뀝니다. 위 영어 단어(Products · New product · Digital product · Content ·
  Customize · Payments · Publish)를 찾아 누르면 순서는 같습니다.
- **상품을 여러 개 올리지 마세요.** 첫 단계에서는 분기 묶음 **하나**만 올립니다.
  상품이 늘면 어느 것이 팔렸는지 알 수 없고, 고칠 곳만 늘어납니다.
- 링크가 나온 뒤에 8장(사이트에 붙이기)을 진행합니다. 그 전에 사이트를 고치지 않습니다.
- 크몽은 **같은 파일로 별도 상품 등록**(가격·설명 동일하게)입니다.

### 워크북 만들기 (파일 준비)

가장 빠른 길은 **사이트의 「인쇄 · PDF」 버튼**입니다. 주별로 인쇄하면 지금 바로 워크북이 나옵니다
(인쇄용 스타일이 이미 들어 있고, 번역도 종이에서는 되살아납니다).

다만 그것만으로는 유료의 값이 약합니다. 팔 수 있는 형태가 되려면 아래가 **파일에만** 있어야 합니다.

| 파일에 담을 것 | 지금 있는가 |
| --- | --- |
| 4주 본문 (섹션 70개 · 항목 351개) | ✅ 웹에 있음 — 인쇄로 뽑을 수 있음 |
| 확인 문제 48문항 + **문항별 해설** | ✅ 데이터에 있음 — 문제와 정답을 **분리 조판**해야 함 |
| 받아쓰기 32문장 + 정답 | ✅ 데이터에 있음 |
| **모범 답안 모음**(쓰기·독해·토론) | ✅ 데이터에 있음 |
| **누적 어휘 색인**(주차·뜻·예문) | ❌ 없음 — 새로 만들어야 함 |
| 표지·차례·여백·필기 레이아웃 | ❌ 없음 — 인쇄용 조판이 필요 |
| **낭독 음성(듣기 팩)** | ✅ `tools/make-audio.mjs` — 받아쓰기·회화·예문을 합성 음성 MP3로 (`_audio/`, gitignore) |

- 이 두 줄(색인·조판)이 **워크북 생성기**가 할 일입니다. `tools/` 에 도구 하나(예: `make-workbook.mjs`)를 두어
  `issues.js` 에서 PDF용 HTML을 뽑고, 헤드리스 Chrome(`browser-test.js` 가 쓰는 방식)으로 PDF를 만들면
  **런타임 의존성 0** 이라는 이 저장소의 원칙을 깨지 않습니다.
- 만들기 전까지는 **팔 것이 없습니다.** 상품 등록은 그다음입니다.

## 7. 고객을 만나는 순서 (퍼널)

```text
검색 유입(주제 키워드) → 무료 웹에서 한 주를 끝까지 읽음 → 단어장·진행률이 쌓임
   → "이걸 종이로 풀 수 있으면 좋겠다" 지점 → 워크북 구매 → 소개·재구매(1년 패스)
```

단계별로 지금 있는 것과 없는 것:

| 단계 | 지금 있는 것 | 보강할 것 |
| --- | --- | --- |
| 유입 | 52주 로드맵·계획 카드(검색 키워드 확보) · og 이미지 · 사이트맵 | 주제별 랜딩 문구, 블로그/커뮤니티 글 |
| 체험 | 4주 전체 무료 + 오디오·받아쓰기·복습 카드 | 첫 화면에서 "종이 워크북이 있다"는 한 줄 안내 |
| 신뢰 | 확인 문제 해설 · 모범 답안 · 한국어 해설 노트 | 정답·해설의 완결성(주당 12문항 해설) |
| 구매 | — | 결제 링크 · 환불·이용약관 조항 · 문의 유형에 `purchase` |
| 유지 | 백업(JSON)·CSV 내보내기 | 새 주 알림 메일(Formspree 유입 명단) |

**이미 있는 자산을 먼저 씁니다.**

- 「새 주 알림」 폼(Formspree)은 **이메일 명단**입니다. 상품이 나오면 여기로 먼저 알립니다. 비용 0.
- 52주 로드맵은 **검색 키워드 목록**입니다. W05~W52의 `theme`·`title`이 곧 앞으로 유입될 검색어입니다.

## 8. 사이트에 붙인 변경 (준비 완료 — 링크만 비어 있음)

정책 문구와 구매 화면은 **미리 붙여 두었습니다.** 팔 상품이 없을 때도 화면이 깨지지 않게,
링크가 비어 있으면 구매 화면 전체가 숨겨지는 방식입니다. 남은 일은 **링크 한 줄**입니다.

| # | 할 일 | 상태 |
| --- | --- | --- |
| 1 | 구매 화면 + 표지 버튼 (`index.html`의 `#buy` · `#buyHero`) | ✅ 붙임 — `data-shop-url`이 비면 **둘 다 숨김** |
| 2 | 상품 링크 넣기 (`data-shop-url` 한 곳) | ⬜ **Gumroad 링크 발급 후** |
| 3 | `terms.html` — 유료 워크북 조항(7일 환불·재배포 금지·카드 정보 미보관) | ✅ 제3조 |
| 4 | `privacy.html` — 결제는 대행사에서 처리, 카드 정보 미수집 | ✅ 4항 |
| 5 | 문의 유형에 `purchase`(구매 문의) — ko·en 양쪽 | ✅ `script.js` · `index.html` |
| 6 | 테스트 — 링크가 한 곳인지, 빈 값이면 숨겨지는지, 약관·방침에 조항이 있는지 | ✅ `smoke-test.js` 3개 검사 |
| 7 | 워크북 PDF 생성기 | ✅ `tools/make-workbook.mjs` (`npm run workbook`) |
| 8 | 듣기 팩 MP3 생성기 — 받아쓰기·회화·예문 | ✅ `tools/make-audio.mjs` (`npm run audio`) |
| 9 | 화면 오디오도 악센트를 화자에 고정(en-US/en-GB) | ✅ `magazine.js` — 파일이 없어도 웹에서 대비가 생김 |

**하지 않기로 한 것**: 발행 주에 "유료" 배지를 달지 않습니다. 웹은 **전부 무료**이므로
배지는 "여기서부터 유료"라는 오해를 만듭니다. 무료라는 사실과 유료(워크북)의 차이는
구매 화면의 `mag.buyLead` 한 줄이 이미 설명합니다.

링크를 넣는 커밋에서는 `sw.js`의 `CACHE_NAME`을 올립니다(`index.html`이 핵심 캐시).

### 리스크와 대응

1. **"웹에 다 있는데 왜 사나"** — 가장 큰 리스크입니다.
   - 대응: 유료의 값을 **형태**에 둡니다(3장). 정답·해설·색인을 한 곳에 모은 것, 인쇄·필기, 오프라인.
   - 그래도 안 되면 그때 **부분 잠금**(W05부터 웹에는 앞 6개 섹션만)으로 전환합니다.
     이건 `issues.js`에 섹션을 다 넣고 화면에서 자르는 방식이라 되돌리기 쉽습니다.
     **먼저 전환율을 재고, 그다음에 바꿉니다.** 추측으로 잠그면 검색 유입부터 잃습니다.
2. **무단 공유** — PDF는 한 번 새면 끝입니다.
   - 대응: 구매자 이메일 워터마크, 재배포 금지 약관, **자주 갱신**(새 주마다 재발행)으로 "계속 받는 값"을 만듭니다.
3. **세금·사업자** — 국내 상시 판매는 사업자등록 대상입니다.
   - 대응: 검증 단계는 크몽(개인 전문가)으로 시작하고, 월 매출이 자리 잡으면 사업자등록 후 직접 채널을 봅니다.
   - MoR 서비스는 세금 처리를 대행하지만, **국내 신고 의무가 사라지는 것은 아닙니다.**
4. **플랫폼 의존** — 한 채널이 막히면 매출이 0이 됩니다.
   - 대응: 파일 원본은 항상 이 저장소에서 만들어 두고(Git에 원본), 채널을 최소 둘 유지합니다.
5. **저작권** — 본문은 전부 자체 집필이고, 오디오는 브라우저 음성합성을 씁니다.
   - 유료 PDF에 **제3자 텍스트·이미지를 넣지 마세요.** 그 순간 재배포 권리가 생깁니다.
