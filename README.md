# EngMon — engmon.monster

`engmon.monster` — 호(issue) 단위로 읽는 **월간 영어 매거진**. 빌드 도구가 필요 없는 정적 사이트(HTML + CSS + JS)입니다.
MonsterLab(`monsterlab.monster`)의 두 번째 서비스입니다.

## 구조

```
index.html     # 매거진 본문 (표지·호 선택기·목차·섹션·복습·단어장·다음 호)
issues.js      # 매거진 데이터(호·섹션) — 이 파일이 콘텐츠의 "DB"
magazine.js    # 매거진 렌더링·오디오·받아쓰기·퀴즈·복습 카드·단어장·진행률
script.js      # 페이지 공통 (한/영 전환, 테마, 강조색, 모바일 메뉴) — EngMon 범위로 정리된 사전
styles.css     # 스타일 (다크/라이트 테마, 강조색 프리셋, 인쇄용, 반응형)
analytics.js   # 방문 분석 (Google Analytics 4) — 측정 ID를 넣기 전에는 아무 것도 안 함
smoke-test.js  # 검증 스크립트 (배포 전 `node smoke-test.js`)
browser-test.js# 헤드리스 Chrome 검증 (스크롤·모바일 레이아웃·실제 클릭)
CNAME          # GitHub Pages 커스텀 도메인 (engmon.monster)
```

- 프레임워크·패키지·빌드 과정 없음. 파일을 그대로 올리면 동작합니다.
- 외부 의존성 없음(시스템 폰트, CDN 요청 없음). 오디오는 브라우저 내장 음성합성(`speechSynthesis`)을 씁니다.
  단, **방문 분석을 켜면**(측정 ID 입력) Google Analytics 스크립트 1개를 불러옵니다 — 아래 "방문 분석" 참고.
- `script.js`가 공용 API(`window.MonsterLab`의 `t`·`toast`)와 `langchange` 이벤트를 노출하고,
  `magazine.js`는 그 두 가지로만 연결됩니다.
- `script.js`는 **공용 API를 먼저 노출한 뒤, 기능별로 `guard()` 안에서 초기화**합니다.
  한 기능이 예외로 죽어도 나머지(특히 언어 전환)는 계속 동작하고, 실패한 기능만 콘솔에 남습니다.

> MonsterLab 본체와 분리된 저장소입니다. 홈페이지·서비스 소개는 [monsterlab.monster](https://monsterlab.monster)에 있습니다.

## 검증 (배포 전)

```bash
node smoke-test.js
```

브라우저 없이 페이지 스크립트를 **실제로 실행**해 보는 테스트입니다(의존성 없음, Node만 있으면 됩니다).
`index.html`의 인라인 스크립트 → `issues.js` → `script.js` → `magazine.js`를 최소 DOM 위에서 돌리고
언어 전환·테마·강조색·매거진 렌더링·호 전환·번역 토글·받아쓰기 채점·퀴즈 점수·복습 카드·단어장 검색까지
클릭을 흉내 내 확인합니다. 현재 **48개 항목**을 검사합니다.

특히 다음을 지켜줍니다.

- **회귀 테스트**: 테마 초기화가 강제로 실패해도 언어 전환이 살아남는지 검사합니다.
- **사전 검사**: `data-i18n` 키가 ko/en 양쪽에 모두 있는지, 한쪽에만 있는 키가 없는지 확인합니다.
- **매거진 검사**: `issues.js`의 호·섹션 수만큼 렌더링되는지, 호 선택기·목차·진행률·점수 요약이 채워지는지 확인합니다.
- **데이터 검사**: 모든 호의 섹션 항목에 ko/en이 있는지, 퀴즈 정답 범위·표 구조·받아쓰기 짝이 맞는지 확인합니다.
- **CSS 회귀**: 스티키 목차(`.issue-aside`)에 `max-height`와 `overflow-y:auto`가 남아 있는지 검사합니다.
  (이 두 줄이 빠지면 목차가 화면보다 길 때 아래쪽 항목을 볼 수 없게 됩니다.)
- **CSS 회귀**: 좁은 화면(≤760px)에서 섹션 머리(`.m-head`)가 줄바꿈되는지 검사합니다.
  (줄바꿈이 없으면 학습 도구가 가로 폭을 다 차지해 제목이 **한 글자 폭으로 찌그러집니다**.)
- **방문 분석**: 측정 ID가 없을 때 **아무 요청도 보내지 않는지**, `file://`·추적 금지에서 멈추는지,
  켜졌을 때 "페이지 방문만" 설정으로 보내는지 확인합니다.

### 브라우저 검증

```bash
node browser-test.js          # 검증만
node browser-test.js --shots  # + .shots/ 에 스크린샷
```

헤드리스 Chrome을 띄워 **실제로 렌더링한 화면**을 잽니다(Chrome 경로는 `CHROME` 환경변수로 지정).

- 목차(사이드바)가 화면보다 길 때 잘리지 않고 **마우스 휠로 끝까지 내려가는지** (뷰포트 1080~600px)
- 모바일/태블릿 폭(820~320px)에서 가로 오버플로·잘림이 없는지, **폭 0으로 찌그러진 글상자가 없는지**
- 터치 스와이프 스크롤, 목차 항목 탭 이동
- 호 전환 · 오늘의 학습 · 단어장 · 복습 카드 · 인쇄 버튼 · 백업 파일 생성
- 인쇄 미디어에서 헤더·버튼이 숨고 한국어 해설은 남는지, 콘솔 에러가 없는지
- 방문 분석(GA4)이 측정 ID 유무에 따라 **요청을 보내는지/안 보내는지** (모든 요청을 가로채 확인,
  구글로는 실제로 보내지 않음)

> `freePort()`로 빈 포트를 잡아 씁니다. 포트를 고정하면 **이전 실행의 Chrome이 남아 있을 때
> 그 인스턴스(옛 프로필)에 붙어** 검사 결과가 엉킵니다.

## 방문 분석 — Google Analytics 4

누가 얼마나 들어오는지 보려면 `analytics.js`가 있습니다. **기본은 꺼진 상태**입니다.

### 켜는 법

1. [analytics.google.com](https://analytics.google.com)에서 계정을 만들고 **속성 + 데이터 스트림(웹)**을 추가합니다
   (주소는 `https://engmon.monster`).
2. 데이터 스트림에 나오는 **측정 ID**(`G-XXXXXXXXXX`)를 복사합니다.
3. `index.html`의 한 줄에 붙여 넣고 배포합니다. 그게 전부입니다.

```html
<script>window.ENGMON_GA4_ID = 'G-XXXXXXXXXX';</script>
```

> 데이터 스트림의 측정 ID를 찾기 어려우면 `index.html`의 두 줄만 보면 됩니다.
> ID를 정하는 곳은 이 한 곳뿐입니다.

### 안 켜지는 경우 (의도된 동작)

| 상황 | 왜 |
| --- | --- |
| ID가 비어 있거나 `G-XXXXXXXXXX` 그대로 | 실수로 남의 계정에 보내는 일을 막습니다 |
| `file://`로 열었을 때 | 로컬 확인이 통계에 섞이지 않게 합니다 |
| 브라우저의 추적 금지(Do Not Track)가 켜짐 | 사용자 선택을 존중합니다 |

이 경우 **스크립트를 내려받지도, 요청을 보내지도 않습니다.** (브라우저 검증으로 확인합니다)

### 무엇을 보내나

**페이지 방문만** 보냅니다 — 조회수, 유입 경로, 기기, 국가, 체류 시간.

- 보내지 않는 것: 학습 행동(섹션 완료·단어 저장·정답률), 입력한 받아쓰기 답, 이름·이메일
- IP 익명화(`anonymize_ip`) 켬, 광고 신호(`allow_google_signals`) 끔
- 그래서 학습 데이터는 여전히 **이 브라우저 안에만** 남습니다 (`localStorage`)

### 알아 둘 점

- GA4는 **자사 쿠키(`_ga`)** 를 씁니다. 쿠키를 쓰지 않는 도구를 원하면
  Plausible · Cloudflare Web Analytics · Simple Analytics 같은 대안이 있습니다
  (각각 계정만 만들고 스크립트 URL과 도메인만 바꾸면 됩니다).
- 유럽 방문자까지 고려한다면 **동의 배너**를 함께 두거나 `analytics_storage`를 `denied`로 시작해
  동의 후 켜야 합니다. 지금은 한국어 서비스 기준으로 쿠키 고지만 바닥글에 넣어 두었습니다.
- 끄고 싶으면 ID를 `''`로 비우면 됩니다 (파일은 그대로 둡니다).

### 확인하는 법

```bash
node smoke-test.js     # 무서운 경우 6가지 + 파일://·추적금지 차단 + 설정 값 검사
node browser-test.js   # 실제 네트워크 요청 검사 (7번 항목)
```

`browser-test.js`는 로컬 서버로 페이지를 열고 **모든 요청을 가로채** 확인합니다.
ID가 비어 있으면 외부 요청이 **0개**인지, ID를 넣으면 `gtag.js`를 **딱 한 번** 부르는지,
그리고 `send_page_view` 외의 이벤트를 보내지 않는지 검사합니다.
**구글로는 아무 것도 보내지 않습니다** (요청을 실패시킵니다).

## 캐시 무효화 (배포 후 "안 바뀐 것처럼 보이는" 문제)

CSS·JS를 참조할 때 `?v=5` 같은 버전을 붙여 둡니다.

```html
<link rel="stylesheet" href="styles.css?v=5" />
<script src="script.js?v=5"></script>
```

**CSS나 JS를 고쳐서 배포할 때는 `index.html`의 `?v=` 숫자를 올리세요.**
그러지 않으면 브라우저나 CDN이 예전 파일을 계속 쓰면서 수정이 반영되지 않은 것처럼 보입니다.

## 배포

정적 호스팅 아무 곳에나 HTML·CSS·JS 파일을 올리면 됩니다
(`index.html`, `issues.js`, `magazine.js`, `script.js`, `analytics.js`, `styles.css`, `CNAME`).

- **GitHub Pages**: 이 저장소를 푸시하고 Pages를 활성화 (커스텀 도메인은 `engmon.monster`)
- **Vercel / Netlify / Cloudflare Pages**: 빌드 명령 없이 루트 디렉터리 지정

> EngMon(`engmon.monster`)은 **저장소를 분리**해 운영합니다.

## 새 호(issue) 추가

`issues.js` 하나로 호를 추가합니다. 서버도 CMS도 필요 없습니다.

```js
var MAGAZINE_ISSUES = [
  { number: 4, slug: 'issue-04', date: '2026-10', level: 'B1', minutes: 45,
    theme: { ko, en }, title: { ko, en }, summary: { ko, en },
    sections: [ /* 아래 필드 조합 */ ] }
];
```

- 배열의 **맨 앞 호**가 기본으로 열립니다. 새 호는 맨 앞에 끼워 넣으면 됩니다.
  표지의 **호 선택기**에 모든 호가 자동으로 나오고, 고른 호는 브라우저에 기억됩니다.
- 섹션 필드는 모두 선택사항이고, 있는 필드만 그려집니다.

| 필드 | 형태 | 쓰임 |
| --- | --- | --- |
| `id` | `'quiz'` | 필수. 앵커·진행률 저장 키. 호 안에서 고유해야 합니다 |
| `kind` | `vocabulary` 등 | 분류. `mag.kind.<kind>` 문구와 짝을 이룹니다 |
| `level` | `A2`…`C1` | 난이도 표시 |
| `title` | `{ ko, en }` | 섹션 제목 |
| `intro` | `{ ko, en }` | 한 줄 도입 |
| `body` | `{ ko:[…], en:[…] }` | **영어가 본문**, 한국어는 번역 블록(가릴 수 있음) |
| `reading` | `[영어 문단, …]` | 독해 지문 |
| `items` | `[{ en, ko, note, meaning, example }]` | 어휘·표현. 저장 버튼과 발음 버튼이 자동으로 붙습니다 |
| `bullets` | `[{ ko, en }]` | 저장 버튼 없는 목록 |
| `table` | `{ caption, head:[{ko,en}], rows:[[…]] }` | 문법 표 |
| `dialogue` | `[{ who, en, ko }]` | 대화문. 줄마다 재생 버튼, 화자별로 다른 목소리 |
| `questions` | `[{ ko, en }]` | 토론 질문 |
| `dictation` | `[{ en, ko }]` | 듣고 받아쓰기 (오답 단어 표시) |
| `quiz` | `[{ q:{ko,en}, options:[…], answer:0, explain:{ko,en} }]` | 즉시 채점 + 점수 + 다시 풀기 |
| `quote` | `{ ko, en }` | 섹션 중간의 강조 인용 |

- `kind` 값은 `mag.kind.<kind>` 문구와 짝을 이룹니다. 새 종류를 쓰려면 `script.js`의 `I18N`에
  `mag.kind.<이름>`을 ko/en 양쪽에 추가하세요.
- **집필 규칙**: 문자열은 작은따옴표로 감싸므로 값 안에 `'`를 쓰지 마세요(축약형은 풀어서).
  값 안에 `':` 조합도 피하세요 — 사전 검사 스크립트가 오인합니다.
  `**굵게**`만 지원합니다.
- **오디오**: `issues.js`의 영어 필드(`body.en`, `reading`, `items[].en`, `dialogue[].en`,
  `questions[].en`)를 문장 단위로 잘라 `speechSynthesis`로 읽습니다.
  화자 이름(Front desk, You)은 **읽지 않고**, 목소리와 음높이로만 구분합니다.
  오디오 파일이 필요 없고 비용도 0입니다.

저장 키: `monsterlab.wordbook`(저장한 단어) · `monsterlab.progress`(섹션 완료) ·
`monsterlab.srs`(복습 단계) · `monsterlab.daily`(오늘 활동 수) · `monsterlab.studyDays`(학습한 날짜) ·
`monsterlab.issue`(보고 있는 호) · `monsterlab.translation`(번역 표시) ·
`monsterlab.rate`(듣기 속도) — 모두 이 브라우저에만 남습니다. (기존 MonsterLab 키 이름을 그대로 씁니다.)
단어장 화면의 **전체 백업(JSON)** / **백업 가져오기**로 이 데이터를 파일 하나에 담아 옮길 수 있습니다.

## 학습 도구

- **읽기**: 호별 읽기 진행률·진행 바, 섹션별 예상 학습 시간(읽기 + 문제 풀이), 섹션 완료 표시, 이어서 읽기
- **듣기**: 섹션 전체 듣기, 대화 전체 듣기, 줄 단위 듣기, 항목별 발음 듣기, 3단계 속도(0.75× / 1× / 1.25×)
- **번역 가리기**: 한국어 도움말(`.trl`)을 한 번에 감춥니다. 영어만 보고 뜻을 떠올리는 연습용
- **받아쓰기**: 문장을 입력해 채점하고, 놓친 단어를 빨갛게 표시하며 정답을 보여 줍니다
- **확인 문제**: 즉시 채점, 정답률 요약, 다시 풀기
- **복습 카드**: 단어장에 담은 표현을 6단계 간격(0·1·3·7·16·35일)으로 다시 봅니다
- **단어장**: 저장·검색·복사·CSV 내보내기·전체 백업/복원(JSON)·비우기
- **호 선택기**: 여러 호를 오가며 보고, 마지막으로 본 호를 기억합니다 (호마다 진행률·완료 표시가 따로 쌓입니다)
- **오늘의 학습**: 오늘 몇 개 활동을 했는지(단어 저장·섹션 완료·정답) 목표 3개 기준으로 보여 주고,
  최근 7일 점과 **연속 학습일·최고 기록**을 함께 표시합니다
- **인쇄 · PDF 저장**: 표지의 버튼으로 호 전체를 종이 한 부로 만듭니다 (학습 도구는 숨기고 한국어 해설은 되살림)

## 접근성·사용성

- 한/영 전환 토글 — 동적 콘텐츠도 `langchange` 이벤트로 함께 다시 그려집니다 (**Alt + L**)
- 다크/라이트/시스템 3단계 테마 **선택** 버튼, 강조색 4종 프리셋 (모두 `localStorage` 저장)
- 영어 지문에 `lang="en"`, 한국어 해설에 `lang="ko"` — 화면 낭독기와 브라우저 음성이 올바른 언어로 읽습니다
- 모바일 햄버거 메뉴, 스크롤 시 헤더 경계선, 맨 위로 가기, 키보드 포커스 링
- `prefers-reduced-motion` 존중
- 사이드바(목차)가 화면보다 길면 **그 안에서 스크롤**할 수 있습니다 (아래 항목이 잘리지 않도록)
- 좁은 화면에서는 목차가 본문 위로 내려가고, 섹션 제목·학습 도구가 두 줄로 나뉘어 글자가 찌그러지지 않습니다
