개인정보처리방침

시행일: 2026년 9월 25일

1. 처리 목적과 기본 방침

EngMon(engmon.monster, 이하 "서비스")은 1년 52주 플랜 영어 매거진을 제공하는 정적 사이트입니다. 회원가입·로그인이 없고, 학습 기록을 서버에 저장하지 않습니다.

2. 학습 데이터 — 브라우저에만 저장

읽기 진행률, 단어장, 복습 단계, 오늘의 학습 같은 기록은 오직 사용자의 브라우저 localStorage에만 남습니다.

  • 저장 키: monsterlab.wordbook · monsterlab.progress · monsterlab.srs · monsterlab.daily · monsterlab.days · monsterlab.issue · monsterlab.translation · monsterlab.rate · monsterlab.lang · monsterlab.theme · monsterlab.accent
  • 이 데이터는 외부 서버로 전송되지 않으며, 제3자에게 제공되지 않습니다.
  • 단어장 화면의 전체 백업(JSON) / 백업 가져오기로 직접 파일로 옮길 수 있고, 브라우저 사이트 데이터를 지우면 함께 삭제됩니다.

3. 문의·알림 신청 폼 (Formspree)

「새 주 알림」 신청과 문의는 별도 서버 없이 Formspree(formspree.io)로 전송됩니다. 이때 운영자가 확인해야 하는 값만 전송합니다.

  • 보내는 값: 이메일 주소(답장·안내용), 이름(선택), 문의 유형, 관련 주, 내용(선택), 접속 도메인
  • 수신된 내용은 답장과 다음 주 안내에만 사용하며, 제3자에게 판매하지 않습니다.
  • Formspree 의 처리 내용은 Formspree 개인정보처리방침을 따릅니다.
  • 스팸 방지를 위해 숨은 함정 칸(허니팟)을 쓰며, reCAPTCHA 를 켠 경우에만 Google 스크립트를 한 번 불러옵니다(기본은 꺼짐).

4. 익명 방문 통계 (Counter.dev)

서비스 개선을 위해 오픈소스 분석 도구 Counter.dev(counter.dev)로 익명 통계를 수집합니다: 페이지뷰, 방문자 수, 유입 경로, 국가, 화면 크기.

  • 쿠키를 사용하지 않으며, IP·이름·이메일 같은 개인 식별 정보를 수집하지 않습니다. 동의 배너가 필요 없습니다.
  • 받아쓰기 답·문의 내용 등 입력창에 적은 값은 전송되지 않습니다.
  • 사이트 ID 를 비워 두면 스크립트를 내려받지도, 요청을 보내지도 않습니다.

5. 쿠키

서비스는 광고·분석용 쿠키를 쓰지 않습니다. 방문 통계(Counter.dev)는 쿠키 없이 동작하고, 학습 데이터는 브라우저 로컬 저장소에만 남습니다.

6. 이용자의 권리

모든 학습 데이터는 사용자 기기에만 있으므로, 브라우저 설정에서 언제든 직접 삭제할 수 있습니다. 문의 폼으로 보낸 이메일의 삭제를 원하시면 아래 주소로 요청해 주세요.
